# API Connectivity Scripts

This directory contains scripts for fetching data from external services.

- `fetch_nivus.R`: Retrieves water level data from the Nivus REST API.
- `fetch_radolan.R`: Downloads RADOLAN precipitation data from DWD.
- `radolan_utils.R`: Shared helper functions for RADOLAN data processing.
- `diag_auth.R`: Diagnostic tool for Nivus API authentication.
