# Visualization Scripts

This directory contains scripts for generating plots and interactive maps.

- `plot_sensors.R`: Generates time-series plots for sensor data.
- `plot_schillerschule.R`: Visualizes Schillerschule-specific correlations.
- `generate_interactive_map.R`: Creates a Leaflet-based interactive sensor map.
- `generate_static_map.R`: Generates a static map with sensor locations.
- `plot_radolan_example.R`: Example script for visualizing RADOLAN data.
