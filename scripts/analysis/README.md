# Data Analysis Scripts

This directory contains scripts for processing and analyzing sensor data.

- `level_analysis.R`: Cleans raw level data and calculates water levels.
- `event_detection.R`: Identifies significant water level events (e.g., flooding).
- `correlate_events.R`: Correlates detected events with precipitation data.
- `correlate_schillerschule.R`: Specific analysis for Schillerschule precipitation data.
- `analyze_experiment.R`: Analysis script for specific experimental runs.
