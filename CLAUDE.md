## Project Overview

**SCIU THALESruhr** is an automated sensor data pipeline for monitoring water levels and flood risk in the Bochum/Hattingen region (Germany). It collects sensor readings from the Nivus DataKiosk API, combines them with DWD precipitation radar (RADOLAN) and Open-Meteo weather forecasts, detects flooding events, and publishes results as an interactive web dashboard and auto-updated README.

## Running the Pipeline

### Full pipeline (local, Windows)
```powershell
.\scripts\automation\automate_fetch.ps1
```

### Individual scripts (run in order for a full refresh)
```bash
# 1. Fetch data
Rscript scripts/api/fetch_nivus.R
Rscript scripts/api/fetch_radolan.R
Rscript scripts/api/fetch_forecast.R

# 2. Analyze
Rscript scripts/analysis/level_analysis.R
Rscript scripts/analysis/event_detection.R
Rscript scripts/analysis/correlate_events.R
Rscript scripts/analysis/check_sensor_health.R
Rscript scripts/analysis/check_risk.R

# 3. Visualize
Rscript scripts/visualization/plot_sensors.R
Rscript scripts/visualization/generate_interactive_map.R
Rscript scripts/visualization/generate_static_map.R

# 4. Update documentation
Rscript scripts/automation/update_readme.R
```

### Automated pipeline (GitHub Actions)
Runs every 6 hours. Outside the 05:00–09:00 UTC daily sync window it only executes when rain is forecasted in the next 24h. Can be triggered manually via `workflow_dispatch`.

## Key Algorithms

**Water level calculation** (`scripts/analysis/level_analysis.R`):
- Baseline = mode of distance readings over a 7-day sliding window (robust to sensor recalibrations)
- Level = Baseline − CurrentDistance
- Values >40 cm are zeroed (obstructions); spikes >5 cm/min are filtered (passing cars)

**Event detection** (`scripts/analysis/event_detection.R`):
- Threshold: level > 1.5 cm; events separated by >20 min gaps are distinct
- Flash flood (Sturzflut): gradient >0.5 cm/min OR duration <45 min with peak >2 cm
- Rain event (Regenereignis): normal rain profile

**DWD risk levels** (used in `fetch_forecast.R` / `update_readme.R`):
- Level 2 (Yellow): >15 mm/1h or >20 mm/6h
- Level 3 (Red): >25 mm/1h or >35 mm/6h
- Level 4 (Violet): >40 mm/1h or >60 mm/6h

## Important Conventions

- All R output files use **UTF-8 with BOM** for Excel compatibility on Windows.
- Interactive Leaflet map loads Plotly charts as **external iframes** (separate `.html` files in `data/output/graphs/`) to avoid script conflicts.
- Raw sensor CSVs (`data/raw/`) are excluded from git (`.gitignore`); processed and output files are committed.
- The README is auto-regenerated by `update_readme.R` — do not edit the dynamic sections manually.
- Sensor station registry is in `data/metadata/sensor_metadata.csv` (5 stations: lat/lon, labels).
